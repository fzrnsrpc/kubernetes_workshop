# Clothing Store Website

This folder contains a simple Flask web application for a basic clothing store.
It allows uploading item images and selling clothes to customers with a small
shopping cart.

## Setup

1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

3. Open `http://localhost:5000` in your browser.

Uploaded images are stored in `static/uploads/`.
